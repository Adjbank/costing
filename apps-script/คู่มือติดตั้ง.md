# คู่มือติดตั้ง · ระบบคำนวณต้นทุนหัวน้ำหอม (Google Apps Script)

ระบบนี้เข้าสู่ระบบด้วยบัญชี Google ของบริษัท Google เป็นผู้ยืนยันอีเมล ระบบรับเฉพาะ **@scentandsense.co.th** และ **@scentandsense.co** ข้อมูลทั้งหมด (ผู้ใช้ บทบาท ราคาวัตถุดิบ ประวัติการแก้ไข) เก็บใน Google Sheet ของบริษัท

ใช้เวลาติดตั้งประมาณ 10 นาที ทำครั้งเดียวด้วยบัญชี **ratchaphon@scentandsense.co.th** (บัญชีที่ติดตั้งจะเป็นเจ้าของระบบและผู้ดูแลระบบถาวร)

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | ใส่ที่ไหนใน Apps Script |
| --- | --- |
| `Code.gs` | ไฟล์ `Code.gs` (โค้ดฝั่งเซิร์ฟเวอร์ + API สำหรับ GitHub Pages) |
| `Prices.gs` | ไฟล์สคริปต์ใหม่ชื่อ `Prices` (ราคาวัตถุดิบเริ่มต้น 1,123 รายการ · ห้ามขึ้น GitHub) |
| `Index.html` | ไฟล์ HTML ชื่อ `Index` (หน้าเว็บ) |
| `appsscript.json` | ไฟล์ manifest (สิทธิ์และการตั้งค่า Web app) |

## ขั้นตอน

1. **สร้าง Google Sheet** ใน Google Drive ของบริษัท ตั้งชื่อเช่น `ระบบต้นทุนหัวน้ำหอม`
2. ในชีต ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ใน Apps Script ไปที่ **การตั้งค่าโปรเจ็กต์ (⚙ Project Settings)** แล้วติ๊ก **"แสดงไฟล์ Manifest appsscript.json ในตัวแก้ไข"**
4. กลับไปที่ **ตัวแก้ไข (Editor)**
   - เปิด `appsscript.json` ลบของเดิม แล้ววางเนื้อหาจากไฟล์ `appsscript.json`
   - เปิด `Code.gs` ลบของเดิม แล้ววางเนื้อหาจากไฟล์ `Code.gs`
   - กด **＋ → สคริปต์** ตั้งชื่อ `Prices` แล้ววางเนื้อหาจากไฟล์ `Prices.gs`
   - กด **＋ → HTML** ตั้งชื่อ `Index` (ไม่ต้องพิมพ์ .html) ลบของเดิม แล้ววางเนื้อหาจากไฟล์ `Index.html`
   - กด **บันทึก (💾)**
5. **รัน setup ครั้งแรก**: เลือกฟังก์ชัน `setup` ในแถบด้านบน แล้วกด **Run**
   - Google จะขอสิทธิ์ กด **Review permissions → เลือกบัญชีบริษัท → Allow**
   - เสร็จแล้วชีตจะมีแท็บ Users, Roles, Settings, Prices (1,123 รายการ), Requests, Visitors, Log
6. **เผยแพร่เป็น Web app**: กด **Deploy → New deployment**
   - Select type: **Web app**
   - Execute as: **Me (ratchaphon@scentandsense.co.th)**
   - Who has access: **Anyone within Scent And Sense** (ชื่อองค์กร Google Workspace ของบริษัท)
   - กด **Deploy** แล้วคัดลอก **Web app URL**
7. เปิด URL นั้น ระบบจะเข้าสู่ระบบด้วยบัญชี Google ของคุณในฐานะผู้ดูแลระบบ จากนั้นกดปุ่ม **"แชร์ลิงก์"** เพื่อส่งให้ทีม

## การใช้งานสำหรับผู้ดูแล

- **เข้าใช้อัตโนมัติ** เปิดไว้ตั้งแต่ติดตั้ง: ทุกบัญชี @scentandsense.co.th / @scentandsense.co เข้าได้ทันทีในบทบาท "ทีมต้นทุน" ปิดได้ที่ "จัดการผู้ใช้และบทบาท → รายชื่อองค์กร"
- **เพิ่มผู้ใช้**: แท็บ "ผู้ใช้" พิมพ์อีเมล เลือกบทบาท ระบบส่งอีเมลแจ้งพร้อมลิงก์
- **คำขอสิทธิ์**: เมื่อปิดเข้าใช้อัตโนมัติ คนที่ยังไม่มีสิทธิ์กด "ส่งคำขอ" แล้วเจ้าของระบบจะได้รับอีเมล อนุมัติได้ในหน้า "รายชื่อองค์กร"
- **ระงับ**: ใช้ "ระงับ" เพื่อกันคนออก ("ลบ" จะทำให้กลับไปใช้บทบาทเริ่มต้นถ้าเปิดเข้าใช้อัตโนมัติอยู่)
- **ประวัติ**: ทุกการเพิ่มผู้ใช้ เปลี่ยนบทบาท และอัปเดตราคา บันทึกในแท็บ **Log** ของชีต
- **การเปลี่ยนสิทธิ์** มีผลเมื่อผู้ใช้เปิดระบบครั้งถัดไปหรือกด "รีเฟรช"

## อัปเดตโค้ดในอนาคต

แก้โค้ดใน Apps Script แล้วไปที่ **Deploy → Manage deployments → ✏ แก้ไข → Version: New version → Deploy** ลิงก์เดิมใช้ต่อได้

## ข้อควรรู้

- **@scentandsense.co ต้องอยู่ใน Google Workspace เดียวกัน** (เป็นโดเมนรองหรือโดเมนแทน) ถ้าเป็น Workspace แยก คนกลุ่มนั้นจะเห็นหน้า "ไม่พบบัญชี Google" ให้แจ้งเพื่อปรับวิธีเผยแพร่
- **อย่าแก้หัวคอลัมน์ (แถวที่ 1)** ในชีต ระบบใช้ชื่อคอลัมน์อ่านข้อมูล แก้ข้อมูลในแถวอื่นได้ แต่แนะนำให้แก้ผ่านหน้าเว็บ
- **ผู้ที่แก้ไข Google Sheet ได้ = เข้าถึงข้อมูลทั้งหมด** แชร์ชีตเฉพาะผู้ดูแล ผู้ใช้ทั่วไปไม่ต้องได้รับสิทธิ์ชีต
- **ดาวน์โหลด Excel**: ถ้าเบราว์เซอร์ไม่ดาวน์โหลดไฟล์ จะมีปุ่ม "บันทึกลง Google Drive แทน" ไฟล์จะอยู่ในโฟลเดอร์ "Scent & Sense · ต้นทุนหัวน้ำหอม (Export)" ของเจ้าของระบบ และแชร์ให้ผู้ขอแบบดูอย่างเดียว
- **สูตรที่กำลังแก้** เก็บในเบราว์เซอร์ของแต่ละคน ราคาวัตถุดิบและสิทธิ์ใช้ร่วมกันผ่านชีต
- คนที่ไม่มีสิทธิ์จะไม่ได้รับข้อมูลราคาเลย (ราคาไม่ได้ฝังในหน้าเว็บ)
